Tujuan Proyek

Yotowawa adalah platform linguistik terpadu untuk digitalisasi dan translasi bahasa daerah Meher dan Woirata. Proyek ini mencakup pengembangan sistem Text-to-Speech (TTS) real-time dan modul pembelajaran interaktif untuk melestarikan kekayaan budaya lokal melalui teknologi web modern.

Digitalisasi Bahasa

Penyimpanan kamus dan struktur tata bahasa daerah dalam database MySQL yang terstruktur.

Real-time TTS

Implementasi teknologi Text-to-Speech untuk membantu pengguna mendengarkan pengucapan kata dalam bahasa daerah secara akurat.

Modul Interaktif

Fitur kuis dan materi pembelajaran yang dirancang untuk menarik minat generasi muda dalam mempelajari bahasa daerah.

Alur Pengembangan

01

Pengumpulan Data

Bekerja sama dengan ahli bahasa untuk mengumpulkan database kata dan fonetik.

02

Penyusunan Sistem

Membangun core platform menggunakan CodeIgniter dengan optimasi query yang cepat.

03

Uji Pengguna

Melakukan pengujian langsung dengan komunitas lokal untuk validasi translasi dan audio.
