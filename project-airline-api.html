Integrasi API Maskapai (NDC)

Implementasi standar IATA NDC untuk modernisasi distribusi layanan penerbangan.

Detail Proyek

Proyek ini melibatkan pengembangan middleware menggunakan Flask untuk menghubungkan sistem internal dengan API NDC dari berbagai maskapai internasional. Fokus utamanya adalah memfasilitasi pemesanan layanan tambahan (ancillaries) seperti pemilihan kursi, bagasi tambahan, dan asuransi melalui protokol XML/JSON yang aman.

Arsitektur Middleware

Membangun lapisan abstraksi yang menstandarisasi berbagai format data maskapai menjadi satu skema internal yang konsisten.

Keamanan Token

Mengelola autentikasi berbasis Bearer Token dan enkripsi data sensitif penumpang selama transmisi API.

Sinkronisasi Data

Memastikan ketersediaan data secara real-time antara sistem maskapai dan database internal Oracle.

Proses Implementasi

01

Analisis IATA NDC

Mempelajari spesifikasi schema XML/JSON yang disediakan oleh provider maskapai.

02

Pengembangan Endpoint

Membangun REST API menggunakan Flask untuk menangani request dari sistem front-end.

03

Uji Coba & Integrasi

Melakukan integrasi testing end-to-end dan validasi data transaksi.
