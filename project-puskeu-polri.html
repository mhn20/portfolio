Super Apps Puskeu Polri

Ekosistem manajemen finansial terpadu untuk instansi kepolisian.

Laravel Django Oracle Keycloak SSO

Detail Proyek

Proyek ini mendigitalisasi proses bisnis di Pusat Keuangan (Puskeu) Polri melalui pengembangan 6 modul utama. Arsitektur sistem dirancang menggunakan kombinasi Laravel dan Django, dengan Oracle Database sebagai penyimpanan data terpusat yang menangani ribuan transaksi personel setiap harinya.

Modul Utama Sistem

Manajemen Pengupahan

Otomasi kalkulasi gaji dan tunjangan personel berdasarkan pangkat dan jabatan.

Perencanaan Anggaran

Penyusunan dan monitoring penyerapan anggaran secara real-time.

Pelaporan Pajak

Integrasi data untuk pelaporan SPT Tahunan dan PPh Pasal 21 secara elektronik.

Pengelolaan Aset

Inventarisasi dan pelacakan barang milik negara di lingkungan finansial.

Perjalanan Dinas

Sistem pengajuan dan verifikasi pertanggungjawaban dana perjalanan dinas.

Dashboard Eksekutif

Visualisasi data finansial strategis untuk mendukung pengambilan keputusan.

Ekosistem Multi-Modul

Integrasi modul pengupahan, anggaran, hingga pelaporan pajak dalam satu dashboard terpusat.

Otomasi DBMS

Implementasi logic kalkulasi kompleks di level Oracle untuk mempercepat rekapitulasi data personel secara otomatis.

Keamanan SSO

Sentralisasi akun menggunakan Keycloak untuk memastikan akses yang aman dan efisien bagi seluruh personel.
